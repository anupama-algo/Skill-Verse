# SkillVerse – Interactive Skill & Career Discovery Platform

## 📌 Project Overview

SkillVerse is an interactive web-based platform developed to help students discover technical skills, explore career domains, and understand suitable learning paths based on their interests.

The platform combines modern UI/UX design with dynamic JavaScript functionality such as quizzes, skill recommendations, popup systems, animations, API integration, and responsive layouts to provide an engaging user experience.


## 🎯 Objectives

* Help students explore modern technology-related skills
* Provide interactive career and skill discovery experience
* Apply frontend development concepts in a real-world project
* Improve user engagement using animations and dynamic UI

## ⚙️ How the Platform Works

1. Users enter the platform through an animated splash screen.
2. The homepage introduces SkillVerse and its features.
3. Users can:

   * Explore technical domains
   * Search for skills dynamically
   * Flip cards to view roadmaps
   * Interact with SkillBot
   * Take quizzes for skill suggestions
   * View recommended courses
4. User information is temporarily stored using Local Storage.
5. Motivational quotes are dynamically loaded using an external API.


## ▶️ How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Run `index.html` in any modern web browser
